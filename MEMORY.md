# Classic Suite UI Standards

Updated after the March 2026 UI/UX pass.

## Launcher
- Search field lives at the top of the game list.
- Launcher uses a richer background treatment instead of a flat color.
- Game entries should read as tappable buttons/list items with clear affordance.

## Shared Interaction Standards
- If a saved in-progress game exists, launch straight back into it automatically.
- "New Game" remains the explicit reset action; resume prompts should be avoided.
- Keep primary actions obvious and consistent: New Game, Restart, Undo, Settings/Stats/Help.
- Favor direct visual guidance on the board over extra explanatory popups for hints.

## Layout Standards
- Prefer layouts that fit without scrolling whenever the board can reasonably scale.
- Card and tile sizing should adapt to screen width/height before introducing scroll.
- Top bars should keep the navigation pattern consistent: Back on the left, centered title, settings/menu on the right.

## Visual Standards
- Keep card surfaces looking like normal playing cards; avoid decorative laminated frames.
- Avoid automatic color-coded solving hints in puzzle games unless the game explicitly depends on them.
- Use consistent rounded surfaces, spacing, and button shapes across games.
